# SMIMP Server

This directory contains the Node.js + Express backend API application for the Smart Material & Inventory Management Platform (SMIMP).

## Running the server locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables in `.env`.
3. Run the development server (runs auto-migrations and seeds initial data on start):
   ```bash
   npm run dev
   ```
   By default, the server API will run at [http://localhost:5000/api](http://localhost:5000/api).

For complete project documentation, setup guides, and seeded account login details, please refer to the main [Root README](../README.md) file.
