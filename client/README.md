# SMIMP Client

This directory contains the React + Vite frontend application for the Smart Material & Inventory Management Platform (SMIMP).

## Running the client locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run Vite local dev server:
   ```bash
   npm run dev
   ```
   By default, the application will run at [http://localhost:5173](http://localhost:5173).

For complete project documentation, setup guides, and seeded account login details, please refer to the main [Root README](../README.md) file.
